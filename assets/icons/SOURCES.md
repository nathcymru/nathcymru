# Icon sources

These icons are copied from [Lucide](https://lucide.dev), a recognised open-source icon library.

Source: https://github.com/lucide-icons/lucide/tree/main/icons
Retrieved: 24 October 2026.
Licence: see LICENSE in this directory (ISC and applicable Feather MIT notices).

The paths are unchanged. The stroke colour is set to #6F7F8F so the icons remain visible on light and dark backgrounds when embedded as images. The README supplies empty alt text for decorative icons beside text labels.

Files: folder-open.svg, cloud-sun.svg, ticket.svg, heart.svg, wrench.svg, house.svg, cpu.svg, code-xml.svg, printer.svg, building.svg, paw-print.svg.
